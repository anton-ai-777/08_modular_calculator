# 🧮 Modular Calculator

Консольный калькулятор на Python с модульной структурой.

Проект демонстрирует, как разделять программу на отдельные модули: основной файл отвечает за взаимодействие с пользователем, математические операции вынесены в отдельный модуль, а вспомогательная логика — в `utils.py`.

## 🚀 Возможности

- ➕ Сложение двух чисел
- ➖ Вычитание двух чисел
- ✖️ Умножение двух чисел
- ➗ Деление двух чисел
- 🛡️ Проверка деления на ноль
- ⚠️ Обработка неправильного ввода
- 🔄 Повторный ввод при ошибке
- 🧩 Разделение логики программы по модулям
- 💻 Работа через консольное меню

## 📁 Структура проекта

```text
08_modular_calculator/
│
├── main.py
├── math_operations.py
├── utils.py
├── .gitignore
├── LICENSE
└── README.md
```

### `main.py`

Главный файл программы.

Отвечает за:

- запуск калькулятора;
- взаимодействие с пользователем;
- выбор математической операции;
- вывод результата.

### `math_operations.py`

Модуль с математическими операциями:

- сложение;
- вычитание;
- умножение;
- деление.

### `utils.py`

Вспомогательные функции для обработки пользовательского ввода и ошибок.

Убедитесь, что установлен Python 3.13 или более новая версия.

