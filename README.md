# 🧮 Modular Calculator

Консольный калькулятор на Python с модульной структурой.

## 🚀 Возможности

- Сложение двух чисел
- Вычитание двух чисел
- Умножение двух чисел
- Деление двух чисел
- Проверка деления на ноль
- Обработка неправильного ввода
- Повторный ввод при ошибке
